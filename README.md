An end-to-end AI-powered Resume Intelligence platform built for students, fresh graduates, and software engineers. It analyses resumes for ATS compliance, visualizes career development paths across 6 tech domains, performs ROI and score analysis for recommended courses, mandates a definitive **DSA Capstone Course**, auto-injects verified credentials and projects into an interactive resume builder, and enables **1-Click Direct Job Applications**.

---

## 🌟 Key Features

### 1. 📊 AI Resume Analyser & ATS Scoring Engine
- **Comprehensive ATS Score (0–100)**: Evaluates resumes across 5 key dimensions:
  - *ATS Structure & Contact Info*
  - *Technical Skills Depth & Relevance*
  - *Quantifiable Results & Metric Multipliers*
  - *Action Verbs & Voice Optimization*
  - *Depth of Experience & Projects*
- **File Upload & Text Parser**: Upload `.pdf` or `.txt` resumes, paste raw text, or select sample profiles.
- **Fresher Candidate Preset**: Defaulted with verified fresher graduate sample data (`Rohan Sharma - CS Class of 2024`) with an initial baseline score of 54/100.
- **Actionable Gap Analysis**: Uncovers resume strengths, critical improvement areas, and missing high-priority ATS keywords.

### 2. 🗺️ Career Development Paths Across 6 Domains
Personalized roadmaps tailored to market demand, salary benchmarks, and open job roles:
- **Full Stack Web Engineering** (React 19, TypeScript, Node.js, PostgreSQL, Docker)
- **Artificial Intelligence & Machine Learning** (Python, PyTorch, Transformers, RAG, Vector DBs)
- **Cloud Architecture & DevOps Engineering** (AWS, Kubernetes, Terraform, GitOps, Linux)
- **Data Science & Big Data Analytics** (SQL, PySpark, Snowflake, Apache Airflow)
- **Cybersecurity & Ethical Hacking** (OWASP Top 10, Burp Suite, SIEM, Penetration Testing)
- **Cross-Platform Mobile Engineering** (React Native, Expo, Reanimated, Offline Storage)

### 3. 🎓 Course Value & ROI Analysis
- **ATS Score Boost**: Displays the exact point increase for each course (+10 to +18 pts).
- **Market Value Score**: Ratings out of 10 based on market demand.
- **Salary Potential Impact**: Estimated compensation upside (e.g., `+$18,000 / ₹5-9 LPA`).
- **Hands-on Capstones**: Every module includes an industry-grade portfolio project.

### 4. 🏆 DSA as the Mandatory Final Capstone
- **Ultimate Data Structures, Algorithms & System Design Capstone**:
- Mandated as the final culminating course across all career paths.
- Provides the maximum ATS boost (+20 pts) and FAANG/Tier-1 coding interview readiness.

### 5. 📝 Auto-Generated Resume & Real-Time Customizer
- **Auto-Injection**: Completing courses automatically injects acquired skills, capstone projects, and verified certificates directly into your resume!
- **Before vs After Score Comparison**: Watch your ATS score climb from **54 to 90+**.
- **Dual Templates**: Switch between *Modern Tech* and *Classic ATS Executive* layouts.
- **One-Click Export**: Download ATS-friendly PDFs (`Download ATS PDF`) or print clean copies.

### 6. 💼 1-Click Direct Job Apply Engine
- **Live Match Scoring**: Calculates real-time % compatibility based on your latest skills.
- **AI Tailored Cover Letter Generator**: Automatically crafts cover letters tuned to your actual projects and target job specifications.
- **Application Tracking**: Tracks pipeline status from *Submitted* to *Under Review* and *Interview Scheduled*.

### 7. 🔐 Candidate Auth & Access Control
- Account access system for tracking course enrollments, earning verified badges, and submitting real job applications.
- Includes fast 1-click demo login options for seamless evaluation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or pnpm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/HRUDAYKUMAR-2006/AI-Resume-Analyser.git
   cd AI-Resume-Analyser
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in your browser:**
   ```
   http://localhost:5173/
   ```
